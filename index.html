Gesture guide

The draw hand is your dominant hand (set in ⚙). Each hand keeps its role while both stay in view. The control hand alone never draws (change in ⚙).

Draw hand

☝️ PointMove cursor. Hold over any button ≈0.8 s to click it.
🤏 PinchDraw / place / grab (thumb + index).
✋ Open palm2D: palm eraser. 3D: release.
✊ FistPen up / pause.

Control hand

✌️ PeaceNext colour
🤟 Three fingersNext tool
🤏 Pinch + move up/down2D: brush size · 3D: depth / scale selected
🤘 Rock (hold)Switch 2D ⇄ 3D

Two-hand combos

🤏 + 🤏2D: shape between both hands · 3D: orbit + zoom view
🤏 grab + 🤏 control3D Select: rotate the grabbed object
🤏 draw + ✋ control open2D: straight line (ruler)
👍 + 👍 (hold)Download (2D: PNG · 3D: STL)
✋ + ✋ (hold 1.5 s)Clear everything
✌️ + ✌️ (hold)Save project file

Tips for good tracking

Undo / Redo are buttons only (left toolbar). Point at them, or pinch on them, so nothing is undone by accident.

  • Good front lighting, plain background, hand 40–80 cm from the camera.
  • Keep the whole hand in view; palm facing the camera works best.
  • Rest your elbow and use “Reach” in ⚙ to draw with small movements.
  • Mouse / touch also works on the canvas for fine corrections.
